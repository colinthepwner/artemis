# Artemis

A visual mod maker for Better Than Adventure! 8.0.1.

Create blocks, ores, liquids, plants, trees, recipes, mobs and biomes through guided editors, paint
their textures in a built in pixel editor with layers and lighting, test the mod in game, and export
a ready to drop jar.

## Download

Grab `Artemis.exe` from [Releases](../../releases). There is no installer, and it updates itself on
launch when a newer release is available.

Building and testing mods needs a JDK 17 installed. Gradle is downloaded automatically.
